# Belyaev Response - инструкция по настройке

Для тимлида/администратора, настраивающего плагин на команду. Все разделы - в том
порядке, в котором они идут на странице настроек (иконка расширения → «Настройки»).

## 1. Оформление и язык
- **Тема**: Тёмная / Светлая / Высокий контраст - на выбор аналитика, применяется на
 главной панели (карточка инцидента) и в popup. Страница настроек красится вместе с темой.
- **Язык интерфейса**: 30 языков, но переводит только «оболочку» главной панели
 (заголовок, вкладки, кнопки) - не саму страницу настроек и не контент (плейбуки,
 наставник, отчёты остаются на русском).

## 2. Лицензия
Только поле ключа (`BLZR-XXXX-XXXX-XXXX-XXXX`) - URL сервера зашит в код, вводить не
нужно (см. `LICENSE_SERVER_SETUP.md`, если вы владелец продукта и разворачиваете свой
сервер). 30 дней Pro-функций доступны сразу после установки без ключа.

## 3. Синхронизация с Grafana (Pro)
Отправка агрегированной статистики BelZor на сервер лицензирования для дашбордов.
Выключено по умолчанию. Включайте только если сервер лицензирования уже развёрнут и
лицензия активна. Псевдоним - необязателен, по умолчанию видно как «anonymous».

## 4. Адаптеры под ваш SIEM
Самый важный шаг для новой команды:
1. Откройте реальную карточку инцидента в отдельной вкладке
2. В настройках вверху страницы - выберите эту вкладку в выпадающем списке
3. В карточке нужной платформы (MP SIEM/RuSIEM/BI.ZONE) впишите URL-паттерн (подстрока
 адреса, например `/incidents/`)
4. «Выбрать на странице» напротив каждого поля → кликните по элементу на вкладке с карточкой
5. Экспортируйте настроенный адаптер («Экспорт / импорт настроек») и раздайте JSON-файл
 остальным аналитикам - не нужно повторять настройку на каждой машине

**Универсальный (fallback) адаптер выключен по умолчанию** - включайте осознанно, он
совпадает с любым сайтом (см. предупреждение прямо в интерфейсе).

## 5. API-ключи для обогащения
VirusTotal / AbuseIPDB - по желанию, для кнопки «проверить» у индикаторов. Anthropic -
для LLM-функций (Pro). Поля - write-only: после сохранения показывают только точки,
не сам ключ повторно. Ключи шифруются (AES-256-GCM) и расшифровываются только в
фоновом процессе расширения.

## 6. База MITRE ATT&CK
Кнопка «Синхронизировать» подтягивает полную официальную базу техник вместо
встроенного курируемого набора (~25 техник) - делайте раз в несколько месяцев, не при
каждой настройке.

## 7. Плейбуки (JSON)
Редактируемый список чек-листов по ключевым словам. Меняйте под свои процессы -
формат отражён в самом текстовом поле, «Сбросить к умолчаниям» - если что-то сломали.

## 8. Обезличивание данных перед LLM
Впишите названия/домены вашей компании (по одному на строку) - они будут заменены на
`[[ORG_N]]` перед отправкой в LLM вместе с IP/MAC/email/ключами/учётками (это работает
всегда, без настройки). Сделайте это до первого использования LLM-функций.

## 9. Уведомления команде
Настройте один или несколько каналов - в панели появится отдельная кнопка на каждый:
- **Slack/Mattermost** - Incoming Webhook URL
- **Telegram** - токен бота (@BotFather) + Chat ID
- **MAX** - токен бота (@MasterBot) + Chat ID
- **Teams** - Incoming Webhook URL канала
- **Jira** - Base URL, email, API-токен (id.atlassian.com), ключ проекта

## 10. Локальная LLM (Ollama)
Для организаций, которым нельзя отправлять данные во внешние облачные LLM даже
обезличенными. Включите чекбокс, укажите URL (по умолчанию `http://localhost:11434`)
и модель. Требует отдельно поднятый Ollama-сервер в вашей инфраструктуре.

## 11. Забота об аналитике
Мягкие напоминания о перерыве при признаках усталости. Включено по умолчанию,
выключайте только по явному запросу команды - это не слежка, данные не покидают браузер.

## 12. Экспорт / импорт настроек команды
Выгружает адаптеры + плейбуки (без ключей) в файл - раздайте новым сотрудникам вместо
повторной настройки с нуля.

## 13. Маркетплейс адаптеров
Требует активной лицензии. «Обновить список» → «Установить» - подтягивает готовый
адаптер, настроенный другой организацией на вашей же платформе SIEM.

## 14. Enterprise-политики (для IT, не аналитика)
Централизованная раздача настроек через `chrome.storage.managed` (Windows-реестр /
Google Admin Console) - ключ лицензии, названия компании, webhook, отключённые
адаптеры. Схема полей - `schema.json` в архиве расширения.

## Связанные документы в архиве
- `QUICKSTART.md` - быстрый старт для рядового аналитика
- `LICENSE_SERVER_SETUP.md` - если вы владелец продукта, разворачивающий свой сервер
- `PRIVACY_POLICY.md` - что и куда передаётся
- `CHANGELOG.md` - история версий и известные ограничения каждой функции
