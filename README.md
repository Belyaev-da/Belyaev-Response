🛡️ Belyaev Response
## 🎯 Что это

**Belyaev Response** — расширение для браузеров (Яндекс, Chrome, Edge),
открывающееся над карточкой инцидента в SIEM и превращающее рабочее место
аналитика в интегрированный центр расследований.
====================

### AI second brain для SOC-аналитика

_Браузерное расширение, которое помогает быстрее и качественнее расследовать
инциденты — прямо в интерфейсе SIEM._

**IOC · MITRE ATT&CK · Playbooks · AI-наставник · DFIR · Incident Reporting**

## ⚡ Возможности

### Расследование инцидентов

- Извлечение IOC: IPv4/IPv6, домены, URL, MD5/SHA-1/SHA-256, email, CVE,
  пути файлов и реестра
- Threat Intelligence: проверка через VirusTotal и AbuseIPDB
- MITRE ATT&CK: автомаппинг техник, визуализация kill chain
- Плейбуки: 9 типов по категориям инцидентов, с поиском владельца актива
  в CMDB/ITSM и 4-уровневой моделью критичности (Mission/Business-critical,
  Business-operational, Office productivity)
- Подсветка IOC прямо на странице SIEM (с подписанной кнопкой в шапке панели)
- Кросс-вкладочная корреляция
- Дифф изменений карточки
- Alert storm: выявление массовых срабатываний
- DFIR-рекомендации по ОС (Windows/Linux/macOS/AstraLinux)

### Отчётность и реагирование

- Отчёт и заключение — выбор формата: Markdown / TXT / HTML
- Формальное заключение: TP / FP / Benign / Эскалация, с ФИО и контактами
  аналитика внизу
- Автоподстановка IOC и техник ATT&CK
- История заключений, подсказки по похожим инцидентам
- Команды реагирования для copy-paste
- PDF-экспорт через печать
- Интеграции со Slack, Mattermost, Telegram, MAX, Jira, Teams

### Обучение SOC-команды

| Уровень | Функционал |
|---------|-----------|
| L1 | Spotlight, пошаговые действия, квизы, система уровней |
| L2 | DFIR-инструменты, рекомендации по нейтрализации |
| L3 | Критерии эскалации, threat hunting, ГосСОПКА |
| Socratic AI | Наводящие вопросы вместо готовых ответов |

### Detection engineering

- Черновики правил Sigma и YARA
- «Второе мнение» по выделенному фрагменту
- Голосовой ввод и горячие клавиши
- Риск-бейдж на иконке расширения

### Интеграция с LLM

GigaChat, YandexGPT, Qwen, Ollama, DeepSeek, Mistral — отдельными пунктами,
плюс универсальный OpenAI-совместимый режим для vLLM/GLM/Foundation-Sec/
Venice/DeepHat/RAG-прокси и любого другого совместимого сервиса. Поддержка
локальной LLM (Ollama) — данные не покидают инфраструктуру организации.

### BelZor и командные метрики

- Геймификация обработки инцидентов, награды за критичность и качество
- Бонусы за MITRE-контекст и TI-проверку
- Ранги аналитиков и локальная статистика
- Отчёты за неделю/месяц/квартал/год, экспорт в CSV
- Синхронизация с Grafana (Pro)

## 🔐 Безопасность данных

Расширение спроектировано с принципом **privacy by design**:

- Адаптеры платформ по умолчанию выключены — расширение не парсит и не
  анализирует содержимое произвольных страниц без явного выбора аналитика
- API-ключи, токены, webhooks, лицензия: локальное хранилище, `AES-256-GCM`
- Секреты расшифровываются только в `background.js`, не передаются в DOM
- Внешние запросы — из service worker, не из контекста SIEM
- Автоматическое маскирование IP/MAC, email, ключей перед отправкой в LLM,
  с превью обезличенного текста перед отправкой
- LLM — только по явному действию аналитика и при настроенном ключе
- Поддержка локальной LLM через Ollama — без внешних сервисов вовсе
- Уведомления команде содержат реальные IOC (намеренно — команде нужны
  настоящие значения для реагирования)

⚠️ Обезличивание — эвристический механизм, а не гарантия. Согласуйте
использование внешних LLM со службой ИБ.

## 🧩 Как это работает

```
Карточка инцидента → Адаптер → Извлечение IOC →
                                    ↓
                        ┌───────────┼───────────┐
                        ↓           ↓           ↓
                    MITRE      Threat        Плейбук
                    ATT&CK      Intel
                        └───────────┼───────────┘
                                    ↓
                        Боковая панель Belyaev Response
                                    ↓
                        Заключение / Отчёт / Коммуникация
```

### Процесс работы

1. Установите расширение в браузер
2. Настройте нужный адаптер через визуальный пикер элементов и включите его
   (по умолчанию все адаптеры выключены)
3. Откройте карточку инцидента
4. Получите IOC, ATT&CK, плейбук, TI в боковой панели
5. Подготовьте заключение и передайте команде

### Почему селекторы настраиваются вручную

MaxPatrol SIEM, RuSIEM, BI.ZONE часто развёрнуты on-prem с кастомной
разметкой. Поэтому расширение не «угадывает», а предлагает выбрать поля
визуально:

`Настройки → Адаптеры → открытая карточка инцидента в отдельной вкладке → «Выбрать на странице» → клик по полю`

Для платформ без специфичного адаптера — «Универсальный», с эвристическими
селекторами по умолчанию.

## 🚀 Установка

### Режим разработчика

1. Скачайте и распакуйте `belyaev-response-v1.8.0.zip`
2. Откройте `chrome://extensions` (или `edge://extensions`, `browser://extensions` в Яндекс.Браузере)
3. Включите **Режим разработчика**
4. Нажмите **Загрузить распакованное расширение**
5. Выберите распакованную папку архива
6. Откройте popup расширения → **Настройки / адаптеры** → настройте нужную платформу

### Настраиваемые интеграции

| Интеграция | Назначение | Нужен ключ |
|-----------|-----------|------|
| VirusTotal | Обогащение IOC | Да |
| AbuseIPDB | Репутация IP | Да |
| Anthropic / GigaChat / YandexGPT / др. | LLM-сводки | Да |
| Ollama | Локальная LLM | Нет |
| Slack / Mattermost / Telegram / MAX / Jira / Teams | Уведомления команде | Да |

> Ключи хранятся только локально в `chrome.storage.local`, в зашифрованном виде.

## ⚠️ Ограничения MVP

- Адаптеры требуют ручной настройки CSS-селекторов (и ручного включения)
- Активация по URL-паттернам; для сложных маршрутов — несколько правил
- Бесплатный VirusTotal имеет квоту; для нагрузки нужен коммерческий ключ
- LLM-сводка — черновик и гипотеза, не автовердикт
- Финальное решение всегда принимает аналитик
- Обезличивание — эвристика, не 100% гарантия
