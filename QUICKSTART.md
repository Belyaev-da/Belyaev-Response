# Belyaev Response - быстрый старт для аналитика

## 1. Установка

1. `chrome://extensions` (или `edge://extensions`, `browser://extensions` в Yandex) → включите «Режим разработчика» (переключатель справа вверху)
2. «Загрузить распакованное расширение» → выберите папку `soc-copilot` из архива
3. Если браузер жалуется на манифест - убедитесь, что распаковали архив целиком, не только часть файлов

## 2. Настройка адаптера под ваш SIEM (один раз)

Без этого шага расширение не поймёт, где на странице искать заголовок/описание карточки.

1. Откройте реальную карточку инцидента в вашем SIEM в отдельной вкладке
2. Откройте настройки расширения (иконка → «Настройки / адаптеры»)
3. В самом верху страницы настроек - выпадающий список «Вкладка с открытой карточкой инцидента». **Выберите именно ту вкладку**, где открыта карточка
4. Найдите блок нужной платформы (MaxPatrol SIEM / RuSIEM / BI.ZONE) → впишите подстроку URL в «URL-паттерны» (например, `/incidents/`)
5. Для каждого поля (Заголовок, Описание, Критичность и т.д.) нажмите «Выбрать на странице» → кликните по нужному элементу на вкладке с карточкой
6. Готово - селектор сохранится автоматически

## 3. Первый разбор инцидента

1. Откройте карточку инцидента → справа появится вертикальная кнопка **BR** → клик открывает панель
2. Вкладка **IOC** - автоматически найденные индикаторы, кнопка «проверить» - обогащение через VirusTotal/AbuseIPDB (нужен свой API-ключ в настройках, необязательно)
3. Вкладка **MITRE** - какие тактики/техники уже видны в тексте карточки
4. Вкладка **Плейбук** - чек-лист шагов реагирования
5. Вкладка **🎓 Наставник** - если вы L1, начните отсюда: пошаговое обучение прямо на этой карточке

## 4. Закрытие инцидента

1. Вкладка **Заключение** → выберите вердикт (TP/FP/Benign/Эскалация), заполните причину и действия
2. «Сохранить как завершённое» → начислится BelZor (награда за инцидент)
3. При настроенной Pro-лицензии - можно сразу разослать заключение в Slack/Telegram/MAX/Teams/Jira

## 5. Оформление и язык (если нужно поменять)

1. Настройки → «Оформление и язык» → выберите тему/язык → «Сохранить»
2. Изменения применяются на всех открытых вкладках автоматически - если панель уже была открыта, можно просто закрыть и открыть её заново, чтобы увидеть новый вид сразу

## 6. Частые проблемы

| Симптом | Решение |
|---|---|
| Кнопка BR не появляется на карточке | Адаптер не настроен под этот URL - см. шаг 2 |
| «Расширение не активно на этой странице» в popup | То же самое - URL-паттерн адаптера не совпадает с текущей страницей |
| IOC/MITRE пустые | Проверьте, что селектор «Описание»/«Контейнер (fallback)» указывает на блок с текстом карточки, а не на пустой div |
| Pro-функции недоступны | Первые 30 дней после установки - они включены автоматически (триал). После - нужна лицензия, см. раздел «Лицензия» в настройках |
